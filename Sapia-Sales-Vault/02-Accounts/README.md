# 02-Accounts

Empty to start with. The agents fill this folder as they work.

- **Company Researcher** writes one research brief per account here, as `{Company}_Brief.md`.
- **Copywriter** writes the email drafts alongside it, as `{Company}_Email1_Draft.md` through `_Email4_Draft.md`.

Both agents create a dated subfolder (`2026-10-01/`) for each batch, so you can see what was researched when.

Nothing here is shared between reps. It is your own account work.
