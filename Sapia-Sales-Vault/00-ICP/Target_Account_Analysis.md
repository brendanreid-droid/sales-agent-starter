## How to fill it in

1. Paste your own target accounts into the table below, one row each. Keep the column headings as they are, the Research Analyst and ICP Scorer agents both read this file by those names.
2. Add the matching rows to `Target_Account_List.csv` alongside it.
3. Leave the ICP Score and Tier columns blank. The ICP Scorer agent fills them in when it runs.

> **Any ICP score you carry over from an old spreadsheet is historical only.** The only score that counts is a current `icp-scorer` pass against `ICP_Scoring_Rubric.md`. An account with no scorer pass yet is unscored, not "whatever tier the old sheet said."
