## How to Run an A/B Test
1. Identify one variable to test (subject line style, opening line, CTA, email length, hook type)
2. Send Variant A to half the batch, Variant B to the other half (same ICP tier)
3. Wait 7 days for data
4. Record results below
5. Adopt the winner as the new standard; retire the loser

**Rule: Test ONE variable at a time.**
